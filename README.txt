WEBSITE ULANG TAHUN BERTAHAP — PRINCESS SHALYA

PERSONALISASI:
- Nama panggilan: Princess Shalya
- Tanggal kejutan: 10 November 2026
- Jam kejutan: 00:00
- Musik: instrumental romantis orisinal yang dibuat langsung oleh JavaScript
  (tekan tombol "Nyalakan musik" karena browser membatasi autoplay).

FILE:
- index.html : struktur halaman dan pesan
- style.css  : tampilan, animasi, dan responsif
- script.js  : hitung mundur, interaksi, dan musik romantis

ALUR:
1. I have something for you + hitung mundur.
2. Tombol Click Me terbuka pada 10 November 2026 pukul 00:00.
3. Kotak kado interaktif.
4. Amplop terbuka dan menampilkan surat.
5. Album foto (pilih foto dari perangkat).
6. Video kenangan (pilih video dari perangkat lalu tekan play).
7. Ucapan akhir dengan maskot alien biru bergaya kartun orisinal.

CATATAN FOTO/VIDEO:
Foto dan video yang dipilih dari perangkat bersifat lokal pada browser tersebut.
Agar penerima melihat media yang sama dari link, letakkan foto/video di folder website,
atur sumber media di HTML, lalu unggah semua file ke hosting.

CARA MENJALANKAN:
Ekstrak ZIP, lalu buka index.html di browser.
Untuk dibagikan sebagai link, unggah file website ke hosting statis seperti
GitHub Pages, Netlify, atau Vercel.


PENGATURAN FOTO & VIDEO MELALUI KODE:
Buat folder "media" sejajar dengan index.html. Masukkan file foto ke folder itu,
lalu ubah array MEMORY_PHOTOS di bagian atas konfigurasi media pada script.js.
Contoh: "media/foto-1.jpg". Urutan array menentukan urutan slide foto.
Masukkan video ke folder yang sama, lalu ubah MEMORY_VIDEO menjadi
"media/video-kenangan.mp4". Tidak ada tombol input/upload media di tampilan website.
